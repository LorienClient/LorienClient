Funkcje

To, co realnie działa

Bez obiecywania rzeczy, których nie ma — tak jak w dokumentacji projektu.

⛏

Logowanie Microsoft

Prawdziwy przepływ Microsoft → Xbox Live → Minecraft, bez podawania hasła w launcherze.

⬇

Pobieranie i start gry

Launcher sam pobiera pliki wybranej wersji i uruchamia Javę w tle.

🎨

Zmiana skina

Bezpośrednio przez oficjalne API Mojang — bez zewnętrznych stron.

⚙

RAM, JVM, rozdzielczość

Pełna kontrola nad ustawieniami uruchomieniowymi, zapisywana i stosowana przy każdym starcie.

🛠

Naprawa gry

Jedno kliknięcie czyści lokalne pliki wybranej wersji, żeby pobrały się od nowa.

🔄

Aktualizacje w tle

Nowa wersja launchera pobiera się sama i instaluje jednym kliknięciem powiadomienia.

🧩

Zarządzanie modami

Zakładka jest w interfejsie, ale funkcja jest jeszcze w budowie.

W PRZYGOTOWANIU
Instalacja

Uruchomienie w trzech krokach

Dla graczy: zwykły instalator .exe. Dla siebie / testerów: poniżej.

1

Pobierz instalator

Uruchom plik Lorien Client Setup.exe pobrany z sekcji poniżej — bez terminala, bez Node.js.

2

Zaloguj się kontem Microsoft

Kliknij „Zaloguj przez Microsoft" i przejdź przez oficjalne okno logowania.

3

Kliknij „Uruchom"

Pierwsze uruchomienie danej wersji pobierze potrzebne pliki — kolejne starty są już szybkie.

Gotowy, żeby zagrać?

Najnowsza wersja instalatora trafia na GitHub Releases przy każdej publikacji.
